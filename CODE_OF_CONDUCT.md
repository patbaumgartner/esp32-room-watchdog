# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, and keep discussion about the code
rather than the person writing it. Harassment, personal attacks, and
discriminatory language are not welcome here.

## Reporting

Report unacceptable behaviour to <contact@patbaumgartner.com>. Reports are
handled privately. The maintainer may remove comments, close issues, or block
accounts that violate this policy.
